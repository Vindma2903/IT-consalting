Консоль администрирования серверов 1С: как установить, зарегистрировать и запустить

23 октября 2026 · Про технологии

Консоль администрирования серверов 1С — это оснастка Windows (MMC), через которую управляют кластером: базами, сеансами, рабочими процессами. Чтобы она заработала, нужны три условия: компонент установлен, библиотека radmin.dll зарегистрирована в той же версии, что и сервер, и компьютер видит агент сервера по сети. Ниже — по шагам, а в конце разбор частых ошибок.

1. Установите компонент администрирования

Консоль ставится вместе с платформой, но только если при установке отмечен компонент «Администрирование сервера 1С:Предприятия». Если на компьютере стоит только клиент, запустите setup.exe полного дистрибутива той же версии, выберите «Изменить» и добавьте этот компонент.

2. Зарегистрируйте утилиту администрирования

Самый простой способ — меню «Пуск» → «1С Предприятие 8» → «Регистрация утилиты администрирования серверов». Запускайте от имени администратора: без прав администратора regsvr32 выдаст ошибку доступа.

То же самое вручную — командная строка от имени администратора:

regsvr32 "C:\Program Files\1cv8\8.3.XX.XXXX\bin\radmin.dll"

Вместо 8.3.XX.XXXX подставьте номер своей версии — это имя папки в C:\Program Files\1cv8\. Для 32-битной платформы путь начинается с C:\Program Files (x86)\.

3. Запустите консоль

«Пуск» → «Администрирование серверов 1С Предприятия». Если ярлыка нет, откройте файл оснастки напрямую:

  • для 64-битной платформы — C:\Program Files\1cv8\common\1CV8 Servers (x86-64).msc;
  • для 32-битной — 1CV8 Servers.msc в той же папке common.

4. Подключитесь к серверу

В дереве слева нажмите правой кнопкой на «Central 1C:Enterprise 8.3 servers» → «Создать» → «Центральный сервер 1С:Предприятия 8.3». Укажите имя компьютера, где работает сервер, и порт агента — по умолчанию 1540. После этого в дереве появятся кластер и информационные базы.
